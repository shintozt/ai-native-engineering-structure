# Dry Run 日志

本目录记录 Harness 在真实工程上的试运行结果。

命名规则：

- `dry-run-log-001.md`
- `dry-run-log-002.md`
- `dry-run-log-003.md`

每份日志必须包含：候选需求、真实项目观察、验证命令、门禁摩擦、知识候选、对模板的修正建议。

Dry Run 日志是原始证据，不等同于正式知识条目。真实 Track 归档后，再把可复用结论写入 `context/learnings/TK-xxx.md` 并登记到 `context/learnings/catalog.md`。

累积 3 份 Dry Run 后，再提炼正式的 `harness/dry-run.md` 机制。
